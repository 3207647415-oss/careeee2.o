# 学生端使用指南

## 一、快速上手

1. 打开首页，点击「开始测评」或直接进入某个专区
2. 完成 42 题职业测评，获取赛道适配度报告
3. 根据报告推荐进入对应专区（考研 / 就业 / 考公）
4. 利用专业详情、院校匹配、简历模板等工具辅助决策

## 二、各模块使用说明

### 2.1 职业测评

- 共 42 题，Likert 五点量表（1=非常不符合 → 5=非常符合）
- 支持随时退出，进度自动保存到浏览器
- 结果包含：霍兰德三字代码、大五剖面图、四赛道适配度雷达图
- 可重新测评覆盖结果

### 2.2 行业认知

- 顶部搜索框支持按行业、岗位、企业名模糊搜索
- 每个行业卡片展示：标签、薪资区间、核心需求、详细描述、发展路径
- 细分岗位与头部企业以卡片形式展开

### 2.3 考研专区

1. 点击专业卡片查看：考试科目、国家线趋势、推荐院校、备考时间线、资料链接
2. 使用「院校智能匹配」：
   - 输入当前 GPA 名次、英语成绩、预估初试分
   - 可按地区、院校层次筛选
   - 点击「匹配」自动生成冲/稳/保三档推荐
3. 每档院校显示：层次、地区、复试线范围、报录比、保护一志愿标记

### 2.4 就业专区

1. 专业卡片展示：校招时间线、推荐企业投递入口、岗位成长路径
2. 简历模板：
   - 选择模板风格（极简 / 项目 / 学生）
   - 填写表单后实时预览
   - 一键下载为 HTML 文件

### 2.5 考公专区

1. 按省份查看：省考时间、笔试科目、招录规模、竞争比
2. 查看本省可报岗位（按专业大类）
3. 国考 / 省考 / 选调生官方入口直达

## 三、数据保存说明

- 测评进度、引导进度、行动项保存在浏览器 localStorage
- 清除浏览器数据将丢失进度
- 不涉及账号系统，无云端同步

## 四、常见问题

**Q：测评结果准吗？**
A：基于霍兰德职业兴趣理论与大五人格模型，结果反映倾向而非绝对判定，建议结合实际经历综合判断。

**Q：院校匹配能直接用来填报吗？**
A：不能。匹配基于历年分数线与报录比的规则模型，当年招生计划、复试线可能变化，请以院校研究生院官网当年公告为准。

**Q：数据什么时候更新？**
A：核心数据整理自 2024 年公开信息。后续会通过 `backend/` 下的爬虫脚本定期刷新。
