# 部署手册

## 一、部署方式选择

| 方式 | 适用场景 | 复杂度 |
|---|---|---|
| 直接打开 | 个人本地使用 | ★ |
| 本地 HTTP 服务 | 开发调试 | ★ |
| Docker | 容器化部署 | ★★ |
| 静态托管（GitHub Pages / Vercel / Netlify） | 公开访问 | ★★ |

## 二、直接打开

```bash
open frontend/index.html
```

> 注意：部分浏览器对 `file://` 协议下的 localStorage 有限制，建议使用本地服务。

## 三、本地 HTTP 服务

### Python

```bash
cd frontend
python3 -m http.server 8765
# 访问 http://127.0.0.1:8765/index.html
```

### Ruby

```bash
cd frontend
ruby -run -e httpd . -p 8765
```

### Node（需安装）

```bash
npx serve frontend -p 8765
```

## 四、Docker 部署

```bash
# 复制环境变量
cp .env.example .env

# 启动
docker-compose up -d

# 访问
open http://localhost:8765
```

## 五、静态托管

### GitHub Pages

将 `frontend/` 目录推送到仓库，在仓库 Settings → Pages 中选择 `frontend/` 目录作为发布源。

### Vercel / Netlify

导入仓库，构建设置：
- Build Command：（留空，无构建）
- Output Directory：`frontend`

## 六、数据采集后端（可选）

`backend/crawler_official_data.py` 用于从官网抓取最新的院校分数线、报录比等数据，刷新内联数据。

```bash
cd backend
pip install -r requirements-crawler.txt
python crawler_official_data.py
```

> 数据仅用于方向性参考，实际报考以院校当年官方公告为准。
