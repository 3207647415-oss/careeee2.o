# 职路导航

> 从学生到社会化成长的一站式决策导航：先理解自己，再理解世界，让每一次选择都有可执行的下一步。

一个面向在校大学生与应届毕业生的职业规划工具。把「我是谁 / 我能去哪 / 怎么去」三件事收进同一个站点，从自我认知、赛道测评，到行业调研、考研择校、求职投递、考公备考，全流程不跳出站外拼凑信息。

---

## 快速开始

项目是**单文件应用**，无需安装、无需构建、无后端依赖。

**方式一：直接打开**

```bash
open empty-window/index.html
```

**方式二：本地服务（推荐，Blob 下载等 API 在 file:// 下可能受限）**

```bash
cd empty-window
ruby -run -e httpd . -p 8765
# 或
python3 -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/index.html>。

首次加载会播放 Apple 风格开场动画，随后进入新手引导问卷（可中途退出，进度自动保存）。

## 功能模块

顶部导航分为三块：首页、迷茫疏导、职业测评，其余入口收在「资源中心」下拉中。

### 职业测评

42 道 Likert 五点量表题，基于职业心理学经典模型设计：

| 模块 | 构成 | 题量 |
|---|---|---|
| 霍兰德职业兴趣（RIASEC） | 现实型 R / 研究型 I / 艺术型 A / 社会型 S / 企业型 E / 常规型 C | 6 型 × 4 题 |
| 大五人格 | 开放性 / 尽责性 / 外向性 / 宜人性 / 情绪稳定 | 5 维 × 2 题 |
| 职业情境 | 风险容忍 / 延迟满足 / 成就动机 | 3 + 2 + 3 题 |

其中 7 道为反向计分题（自动 `6 - 原始分` 反转）。所有题目采用第一人称陈述句表述，避免激起防御性作答。

**评分引擎**：维度均分（1–5）→ 按职业心理学权重映射到四条赛道（考研 / 就业 / 考公 / 创业），输出：

- 霍兰德三字代码（如 `RIA`）及六型释义
- 大五人格剖面（5 条维度分）
- 四条赛道适配度百分比
- 基于维度实时数值的个性化解读

### 行业认知

10 大行业（互联网、金融、教育、医疗、制造业、新能源、文化传媒、咨询、房地产、公务员），每个行业包含：

- 3–5 个核心细分岗位：职责、应届生薪资区间、入门能力要求
- 校招热度最高的 10 家头部企业
- 2024–2025 行业发展趋势总结

顶部搜索框支持按**行业名 / 岗位名 / 企业名**检索。

### 考研专区

30 个考研热门专业，每个专业覆盖：

- 完整考研科目（公共课 + 专业课）、历年国家线趋势
- 对应院校：招生方向、学费学制、调剂难度说明
- 一站式时间节点：预报名、正式报名、准考证打印、初试、查分、复试的官方入口
- 备考资料：公共课名师课程推荐、专业课资料获取渠道

**院校匹配工具**（核心功能）：

- 内置 **84 所真实考研院校**：34 所自划线 985 + 25 所热门 211 / 学科强校 + 25 所高性价比双非
- 每所院校记录：层次、地区、是否 34 所自划线、考研热度、2024 复试线区间、报录比、是否保护一志愿、学科特色
- 输入成绩排名、英语水平、预估分数后，按加权公式计算**用户综合竞争力（0–100）**
- 每所院校按「层次 + 热度 + 自划线 + 复试线中位数 + 保护一志愿政策」计算**难度分**
- 以「难度分 − 竞争力」差值自动划分 **冲刺 / 稳妥 / 保底** 三档并梯度排序，每档保证至少 3 所
- 支持**地区筛选**（北京 / 上海 / 华东 / 华南 / 华中 / 西南 / 西北 / 东北）与**院校层次筛选**（只看 985 / 985+211 / 双一流及以上 / 双非也可）

### 就业专区

对应 30 个专业，每个专业包含：

- 完整校招时间线：秋招、春招、暑期实习的关键节点
- 对口头部企业校招投递入口、主流实习平台直达链接
- 成长路线细化到大学每学期的任务，附证书 / 比赛的官方报名入口
- **3 套通用简历模板**（极简一页型 / 项目作品型 / 学生综合型），站内 iframe 直接预览，支持下载为独立 HTML 文件

### 考公专区

- 27 个省级行政区的省考时间、考试科目、招录概况
- 按专业可报岗位大类、历年平均招录人数、平均竞争比
- 一站式官方入口汇总：国考 / 省考 / 事业单位 / 选调生的报名、准考证打印、成绩查询
- 行测 5 大模块与申论 5 类题型的备考方法、常用资料推荐

### 迷茫疏导 / 赛道对比 / 避坑指南

- 迷茫疏导：按当前困惑场景给出可执行的下一步
- 赛道对比：考研 / 就业 / 考公 / 创业在时间成本、金钱成本、稳定性、薪资、门槛上的横向比较
- 避坑指南：每条赛道常见的认知误区与纠正建议

## 交互与体验设计

- **进度持久化**：测评与新手引导的答题进度写入 `localStorage`，下次进入可选择「继续上次作答」或「重新开始」
- **随时退出**：所有分步问卷右上角提供「退出」按钮，二次确认后平滑返回首页，不刷新整页
- **可回退**：职业测评支持「上一题」，允许返回修改答案
- **外链不打断**：所有外部链接统一 `target="_blank" rel="noopener"`，新标签页打开，用户不离开本站
- **动画**：Apple 风格极光开场动画，纯 CSS 实现，不影响首屏可用性

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 结构 | 原生 HTML5 | 语义化标签 + 多页面 section 切换 |
| 样式 | Tailwind CSS（CDN） | 自定义品牌色 `brand` / `mint` / `soft` |
| 逻辑 | 原生 JavaScript（ES5 语法风格） | 无框架、无构建、无打包 |
| 数据 | 内联 JSON 结构 | 全部前端持有，无后端接口 |
| 持久化 | localStorage | 测评进度、引导进度、行动项进度 |
| 文件导出 | Blob API + iframe | 简历模板预览与下载 |

设计取向：**零依赖、零构建、可离线分发**。把整个应用塞进一个 HTML 文件，双击即可运行，便于分享给非技术背景的同学使用。

## 数据说明

- 所有外部链接均指向官方公开地址（研招网、教育部考试院、各省人事考试网、企业校招官网等）
- 院校分数线、报录比、竞争比为 2024 年公开信息整理，用于**方向性参考**
- 行业薪资为应届生区间估计，因城市、企业、岗位而异
- 院校匹配结果基于规则评分模型，**不构成报考决策依据**；具体招生目录、当年复试线、专业是否招生，务必以院校研究生院官网当年公告为准
